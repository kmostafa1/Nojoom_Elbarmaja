Training Path

# Lecture HTML Focus CSS Focus JavaScript Focus Main Output
1 My First Webpage Page structure, title, headings, paragraphs Background color and text color Not introduced yet Create a page called My First Webpage with your name, a heading, and one paragraph. Then give the page a background color and text color.
2 My Favorite Things Headings, paragraphs, sections, ordered and unordered lists Fonts, heading styles, spacing Not introduced yet Create a My Favorite Things page with favorite foods, games, books, or hobbies. Style the text to make it easy and fun to read.
3 Interactive Content: Images, Links, Buttons, and Tables Images, links, buttons, and tables Button style, image size, table borders Not introduced yet Create a My Weekly Schedule page with an image, link, button, and schedule table. Then style the table and button.
4 Mini Project: All About Me Complete personal webpage structure Simple personal theme with colors, spacing, and readable typography Not introduced yet Build an All About Me webpage with an introduction, hobbies, weekly activities, favorite website, image/avatar, and button.
5 Visual Identity: Colors, Backgrounds, and Typography Reuse existing project sections Color schemes, backgrounds, typography, readability Not introduced yet Redesign the All About Me project using one theme: space, fantasy book, sports, or gaming.
6 Card Design with the CSS Box Model Card HTML structure Box Model, card spacing, borders, padding, margin Not introduced yet Create three character cards: hero, villain, and magic item.
7 Flexbox Card Gallery Multiple card sections inside a container Flexbox layout, gap, wrapping, alignment Not introduced yet Build a gallery with at least four cards inspired by a game, book, sport, or fantasy world.
8 CSS Project + JavaScript Sneak Peek Complete card page structure with buttons Visual identity, Box Model, Flexbox, hover effects, reusable CSS Only two previews: onclick alert and onclick background color change Create a Creative Character Cards page with at least four cards. Add one button that shows an alert and one button that changes the page background color.
9 JavaScript Fundamentals: Making Pages Think Buttons and output areas for JavaScript demos Simple layout for JS examples Variables, basic syntax, strings, numbers, booleans, console.log Create a My First JavaScript Page that stores student name, age, favorite hobby, and prints them to the console.
10 DOM Manipulation and Button Events Elements with IDs and buttons Style-ready elements for dynamic changes getElementById, textContent, style, addEventListener, click events Create a page where buttons change the heading text, text color, and background color.
11 Control Flow and Logic Apps Inputs, buttons, counters, and result areas Simple app styling for readability if/else, comparison operators, logical decision-making, counter logic, guessing game logic Build a digital counter with increase, decrease, and reset buttons. Then build a number guessing game.
12 Final Interactive App Challenge App layout structure for Tic Tac Toe or Smart To-Do List Polished app interface with clear states and readable design Events, DOM manipulation, control flow, arrays or dynamic elements, full logic integration Choose one final app: Tic Tac Toe or Smart To-Do List. Build the layout, styling, and JavaScript logic.
