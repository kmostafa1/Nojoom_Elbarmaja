Parent / Guardian Safety Guide

A family-friendly guide explaining what children will learn and how to keep their web projects safe.

Back to Home Start Lessons

What Learners Will Build

Personal Webpage

Students create an “All About Me” page using safe, non-private information.

Creative Card Gallery

Students design cards inspired by games, books, characters, hobbies, or creative themes.

Interactive JavaScript Apps

Students build logic-based apps such as counters, guessing games, Tic Tac Toe, or a To-Do List.

Core Skills

HTML for structure, CSS for design, and JavaScript for interactivity and problem-solving.

Important Online Safety Rules

  • Children should not publish home addresses, phone numbers, school addresses, private schedules, or personal IDs.
  • Use avatars, drawings, icons, or teacher-provided images instead of real personal photos unless approved by a parent or guardian.
  • Ask an adult before uploading or publishing any website online.
  • Use respectful content. Do not publish anything that could embarrass, expose, or hurt another person.
  • Do not copy images, names, or content from unknown websites without permission or teacher guidance.
  • Only run code provided by the teacher or code the learner understands.

Recommended Safe Content

Instead of... Use...
Full real name First name, nickname, or fictional project name
Real personal photo Avatar, emoji, drawing, or safe classroom image
Home address or school address General country/city only if approved by an adult
Private phone/email No contact information on student projects
Exact daily schedule General hobbies or sample weekly activities

How Parents Can Support Learning

Ask About the Project

Ask: “What did you build?”, “What was difficult?”, and “What did you fix?”

Encourage Problem Solving

Instead of giving the answer, encourage the learner to use the Debugging Corner and test small changes.

Review Before Publishing

Check the page for private information, unsafe images, and respectful language before sharing it.

Celebrate Progress

Focus on improvement, creativity, and persistence rather than perfect code.

Publishing Guidance

For children aged 10–15, local practice is usually enough. If a project will be published online, a parent, guardian, or instructor should review the content first.

Before Publishing Check
Privacy No private personal, family, school, or contact details.
Images Images are safe, approved, and copyright-friendly.
Links External links go only to safe, appropriate websites.
Code JavaScript does not collect personal information or redirect users unexpectedly.
