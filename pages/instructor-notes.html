A practical delivery guide for instructors teaching the 12-lecture HTML, CSS, and JavaScript course.

Teaching Rule

HTML

Question: What is on the page?

Use HTML to explain structure: headings, paragraphs, images, buttons, lists, tables, cards, and app layout.

CSS

Question: How does it look?

Use CSS to explain color, spacing, typography, layout, cards, Flexbox, and visual identity.

JavaScript

Question: What happens when the user interacts?

Use JavaScript to explain clicks, variables, DOM changes, conditions, logic, and app behavior.

Core Delivery Pattern

Show the final result first, build it step by step, let students customize, then finish with a challenge.

Teacher Guide

Teaching Rule

HTML answers: What is on the page?

CSS answers: How does it look?

JavaScript answers: What happens when the user interacts?

JavaScript Timing

Do not introduce JavaScript before Lesson 8. Lesson 8 uses only onclick alert and background color change. Full JavaScript starts in Lesson 9.

Recommended Class Flow

  1. Show the final result.
  2. Build the HTML structure.
  3. Add CSS design.
  4. Add JavaScript only when the lesson requires it.
  5. End with a challenge.

Opening Script

Suggested wording:

“Today we are learning how websites are built. HTML gives the page structure, CSS makes it look good, and JavaScript makes it respond when people click, type, or play with it. We will build small pieces first, then combine them into real projects.”

Recommended Lesson Flow

Stage Instructor Action Student Action
Warm-up Ask one review question from the previous lesson. Answer verbally or point to code examples.
Preview Show the final output before coding. Identify what they will build.
Live coding Code slowly and explain each line. Follow along and ask questions.
Guided activity Support students as they build the main task. Complete and personalize the activity.
Try This Change Encourage small experiments. Modify one detail and observe the result.
Debugging Use Debugging Corner instead of fixing the code immediately. Compare the problem, reason, and fix.
Reflection Ask what changed and why. Explain what they learned in their own words.

Lesson-by-Lesson Teaching Notes

Lessons Instructor Focus Common Student Difficulty Teaching Tip
1–4 HTML structure with light CSS. Missing closing tags, misplaced content, and unclear file structure. Repeat: content must go inside body. Use indentation as a visual guide.
5–8 CSS design, Box Model, Flexbox, and creative cards. Confusing margin and padding; Flexbox container versus items. Use the “trading cards on a table” analogy for Flexbox.
8 Only a JavaScript sneak peek. Students may ask for full JavaScript explanation early. Say: “This is a preview. We learn the real JavaScript system from Lesson 9.”
9–12 JavaScript variables, DOM, events, conditions, and apps. Case-sensitive IDs, missing quotes, and logic errors. Test after every small change and read error messages slowly.

Classroom Management Tips

For ages 10–12

  • Use starter files more often.
  • Keep typing sections short.
  • Pair students for debugging.
  • Give visual examples before code.

For ages 13–15

  • Give more independent challenge time.
  • Ask students to explain code behavior.
  • Use peer review for projects.
  • Encourage creative themes and extensions.
