Guided Activity

Task: Build a gallery with at least four cards inspired by a game, book, sport, or fantasy world.

Challenge: Make the layout work on narrow screens by using flex-wrap.

Responsive Design with @media

Use @media to change styles for different screen sizes. This helps the card layout work on phones and tablets.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Create a card container.
  2. Place multiple card sections inside the container.
  3. Add display: flex to the container.
  4. Use gap, justify-content, align-items, and flex-wrap.
  5. Resize the browser window to test wrapping.
  6. Improve spacing and alignment.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Change justify-content to space-around and compare the layout.
  • Increase the gap between cards.
  • Add two more cards and check if the layout wraps.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Add six cards and test how they wrap on a small screen.
  • Try different justify-content values and compare the layout.
  • Create a centered card gallery with a title and subtitle.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Cards are stacked only vertically display: flex may be missing on the container. Add display: flex to the card container.
Cards overflow on small screens flex-wrap may be missing. Add flex-wrap: wrap.
Spacing is uneven Manual margins may conflict. Use gap on the Flexbox container.
