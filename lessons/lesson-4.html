Safety Note for Children

This lesson includes a personal webpage, so privacy is very important.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>All About Me</title>

  <!-- External CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- External JS file -->
  <script src="script.js" defer></script>
</head>
<body>
  <h1>All About Me</h1>

  <nav>
    <a href="#intro">Introduction</a>
    <a href="#hobbies">Hobbies</a>
    <a href="#activities">Activities</a>
  </nav>

  <figure>
    <img src="images/profile.png" alt="Profile avatar" width="180">
    <figcaption>My safe profile avatar for this webpage.</figcaption>
  </figure>

  <h2 id="intro">Introduction</h2>
  <p>Hello! My name is Kareem. I am learning how to build websites.</p>

  <h2 id="hobbies">My Hobbies</h2>
  <ul>
    <li>Football</li>
    <li>Gaming</li>
    <li>Reading</li>
  </ul>

  <h2 id="activities">My Weekly Activities</h2>
  <table>
    <tr>
      <th>Day</th>
      <th>Activity</th>
    </tr>
    <tr>
      <td>Monday</td>
      <td>Sports</td>
    </tr>
  </table>

  <a href="https://www.wikipedia.org">Visit Wikipedia</a>
  <button>Say Hello!</button>
</body>
</html>

Guided Activity

Task: Build an All About Me webpage with an introduction, hobbies, weekly activities, favorite website, image/avatar, and button.

Challenge: Add extra sections: My Dream Job, My Superpower, or Places I Want to Visit.

Navigation with

Use <nav> to group important page links. In this lesson, navigation links jump to sections on the same page.

Image Captions with Figure

Use <figure> to group an image with its caption. Use <figcaption> to describe the image. This fits well in the All About Me project because the avatar image has a clear caption.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Plan the sections of the All About Me page.
  2. Build the HTML structure with heading, introduction, hobbies, table, link, and button.
  3. Add safe personal content without private details.
  4. Apply a simple CSS theme with colors and spacing.
  5. Check that the page is organized and readable.
  6. Review the project using the rubric.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Add a new section called My Dream Job.
  • Style the table with a different border color.
  • Change the button text and color.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Add a personal theme such as space, sports, fantasy, or gaming.
  • Add a safe avatar image instead of a personal photo.
  • Create a navigation area that links to sections on the same page.

Project Rubric: All About Me

Use this rubric to review the personal webpage project.

Skill Excellent Good Needs Practice
HTML structure Complete structure with clear sections Mostly complete with minor issues Missing important structure
Content organization Introduction, hobbies, schedule, link, and button are clear Most required content is present Content is incomplete or hard to follow
CSS theme Consistent colors, readable text, and good spacing Some styling is applied Little or no styling
Safety Uses safe personal information and safe images Mostly safe with minor concerns Includes private or risky information
Creativity Personal, original, and engaging Some customization Very basic

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Page looks unorganized Sections may not be separated clearly. Use headings and spacing for each section.
Table borders missing CSS border may not be applied to th and td. Style both th and td elements.
Button looks plain Button CSS may be missing. Add padding, background color, and border-radius.
