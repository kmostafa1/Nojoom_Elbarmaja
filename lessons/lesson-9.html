Safety Note for Children

This lesson uses JavaScript. Only run code you understand or code provided by your teacher.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

Guided Activity

Task: Create a My First JavaScript Page that stores student name, age, favorite hobby, and prints them to the console.

Challenge: Create three variables: favoriteGame, favoriteColor, and dreamJob. Print all three using console.log.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Create a simple HTML page for JavaScript practice.
  2. Add a script tag.
  3. Create variables using let and const.
  4. Store strings, numbers, and booleans.
  5. Print values using console.log.
  6. Open the browser console and check the output.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Create a variable for favoriteFood and print it.
  • Change let to const for a value that should not change.
  • Print a full sentence using a variable.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Create variables for name, age, hobby, and dream job.
  • Use console.log to print a full sentence using variables.
  • Change a let variable value and print it before and after.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Console shows an error A variable name or quote may be wrong. Check spelling and matching quotes.
Variable prints undefined The variable may not have a value. Assign a value before using console.log.
Code does not run Script tag may be missing or placed incorrectly. Place JavaScript inside script tags.
