Guided Activity

Task: Create three character cards: hero, villain, and magic item.

Challenge: Give each card a different theme color while keeping the same reusable card class.

Semantic Cards with

A card can be written as an <article> when it represents standalone content, such as a character, item, or story card.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Create the HTML structure for one card.
  2. Add card content: icon, title, description, power, and button.
  3. Apply box-sizing: border-box.
  4. Style the card using width, padding, border, margin, and border-radius.
  5. Duplicate the card to create more examples.
  6. Check spacing between cards and inside each card.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Increase card padding and see how the card changes.
  • Change border-radius to make sharper or rounder cards.
  • Create a special villain card with a different border color.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Create three card types: hero, villain, and item.
  • Use a different border style for each card type.
  • Add a hover effect that slightly moves the card.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Card size changes unexpectedly Padding and border may affect width. Use box-sizing: border-box.
Cards touch each other Margin or gap may be missing. Add margin around cards or gap in the container.
Content is too close to edge Padding is too small. Increase padding inside the card.
