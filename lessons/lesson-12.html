Safety Note for Children

This lesson creates an interactive app. Keep tasks, names, and sample data safe and classroom-friendly.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Smart To-Do List</title>

  <!-- External CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- External JS file -->
  <script src="script.js" defer></script>
</head>
<body>
  <h1>Smart To-Do List</h1>

  <input id="taskInput" type="text" placeholder="Write a task">
  <button id="addTask">Add Task</button>

  <ul id="taskList"></ul>
</body>
</html>

JavaScript Example 
const input = document.getElementById("taskInput");
const addButton = document.getElementById("addTask");
const list = document.getElementById("taskList");

addButton.addEventListener("click", function() {
  if (input.value === "") {
    alert("Please write a task first!");
  } else {
    const item = document.createElement("li");
    item.textContent = input.value;

    item.addEventListener("click", function() {
      item.classList.toggle("completed");
    });

    list.appendChild(item);
    input.value = "";
  }
});

Guided Activity

Task: Choose one final app: Tic Tac Toe or Smart To-Do List. Build the layout, styling, and JavaScript logic.

Challenge: Add one advanced feature: scoreboard, priority, completed count, reset button, filters, or localStorage saving.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Choose the final app: Tic Tac Toe or Smart To-Do List.
  2. Plan the required HTML elements.
  3. Create a clean CSS interface.
  4. Write JavaScript for user interactions.
  5. Add decision-making logic and state updates.
  6. Test the app, fix bugs, and review with the rubric.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Add a delete button to each task.
  • Add a completed task counter.
  • Add a reset button for the whole app.

Level Up Tasks

Problem-solving Includes decision-making, validation, or state tracking Some logic decisions included Little logical behavior
Advanced feature Adds a useful extra feature Attempts an extra feature No extra feature attempted

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Task is not added The button event may not be connected. Check addEventListener on the correct button.
Empty tasks are added The if condition may be missing. Check input.value before creating a task.
Completed style does not show CSS class name may not match JavaScript. Check classList.toggle('completed') and .completed CSS.
