Safety Note for Children

This lesson may include personal text, images, or links. Keep your webpage safe.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Favorite Things</title>

  <!-- External CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- External JS file -->
  <script src="script.js" defer></script>
</head>
<body>
  <h1>My Favorite Things</h1>

  <p>I <em>really enjoy</em> learning new skills and building creative webpages.</p>
  <p><strong>Important:</strong> HTML helps us organize content clearly.</p>

  <h2>Favorite Games</h2>
  <ul>
    <li>Minecraft</li>
    <li>Roblox</li>
    <li>Chess</li>
  </ul>

  <h2>Top 5 Things I Want to Learn</h2>
  <ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>Animation</li>
    <li>Game design</li>
    <li>JavaScript</li>
  </ol>
</body>
</html>

Guided Activity

Task: Create a My Favorite Things page with favorite foods, games, books, or hobbies. Style the text to make it easy and fun to read.

Challenge: Create a Top 5 Things I Want to Learn list and style the section title.

Text Emphasis with

Use <em> when you want to emphasize a word or phrase. Browsers usually display emphasized text in italic.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Create a main heading for the page.
  2. Add sections using h2 headings.
  3. Write one paragraph about favorite things.
  4. Add an unordered list and an ordered list.
  5. Use CSS to style font, headings, margin, and line height.
  6. Refresh the browser and check readability.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Change the font size of h1 to 44px.
  • Add another list called My Favorite Foods.
  • Change the h2 color to a new color.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Create three sections: Games, Foods, and Skills.
  • Use both an ordered list and unordered list on the same page.
  • Add a class to one section and style it differently.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
List bullets look wrong li tags may not be inside ul or ol. Place every li inside a list container.
Text spacing feels crowded line-height or margin may be too small. Increase line-height or add margin.
Heading style does not apply The CSS selector may not match the HTML tag. Check that h1, h2, or class names are correct.
