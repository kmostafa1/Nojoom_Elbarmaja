Safety Note for Children

This lesson may include personal text, images, or links. Keep your webpage safe.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

Guided Activity

Task: Redesign the All About Me project using one theme: space, fantasy book, sports, or gaming.

Challenge: Create three theme palettes and choose the strongest one.

Readable Width with max-width

Use max-width to stop content from becoming too wide on large screens. This makes text easier to read.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Choose a theme such as space, fantasy, sports, or gaming.
  2. Select a small color palette.
  3. Style the page background and header area.
  4. Improve typography using font size, line height, and letter spacing.
  5. Check contrast and readability.
  6. Compare the page before and after styling.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Create a space theme using dark blue and white.
  • Try a fantasy theme using purple and gold.
  • Change letter spacing and compare the result.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Create two different color palettes and compare them.
  • Use a gradient background.
  • Create a dark-mode version of the same design.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Colors do not match Too many unrelated colors may be used. Choose 3–5 colors and reuse them.
Text is hard to read Color contrast may be too low. Use dark text on light backgrounds or light text on dark backgrounds.
Background overwhelms content The background may be too strong. Use softer colors or add a white content panel.
