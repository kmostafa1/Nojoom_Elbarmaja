  • Create hyperlinks using a and href.
  • Add buttons as HTML page elements.
  • Build tables using table, tr, th, and td.

Safety Note for Children

This lesson may include personal text, images, or links. Keep your webpage safe.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Weekly Schedule</title>

  <!-- External CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- External JS file -->
  <script src="script.js" defer></script>
</head>
<body>
  <h1>My Weekly Schedule</h1>

  <img src="images/profile.png" alt="Profile avatar" width="200">

  <table>
    <tr>
      <th>Day</th>
      <th>Activity</th>
    </tr>
    <tr>
      <td>Monday</td>
      <td>Football Practice</td>
    </tr>
    <tr>
      <td>Tuesday</td>
      <td>Reading</td>
    </tr>
  </table>

  <a href="https://www.wikipedia.org">Visit Wikipedia</a>
  <button>Click Me</button>
</body>
</html>

Guided Activity

Task: Create a My Weekly Schedule page with an image, link, button, and schedule table. Then style the table and button.

Challenge: Create a Favorite Characters table and apply a unique border color.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Add a page heading.
  2. Insert an image with src, alt, and width.
  3. Create a table with headers and at least two rows.
  4. Add a link and a button.
  5. Style the image, table, and button with CSS.
  6. Test the link and check that all table rows display correctly.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Change the button background color.
  • Add another row to the table.
  • Change the image width to 150 or 250.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Add two images and give each one a different width.
  • Create a table with at least four rows.
  • Style the button with hover effect using CSS.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Image does not load The image path or filename may be wrong. Check spelling, folder name, and file extension.
Link does not open href may be missing or incorrect. Add a valid URL inside href.
Table layout is broken tr, th, or td tags may be missing. Check rows first, then cells inside each row.
