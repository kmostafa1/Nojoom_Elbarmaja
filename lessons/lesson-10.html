HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>DOM Button Events</title>

  <!-- External CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- External JS file -->
  <script src="script.js" defer></script>
</head>
<body>
  <h1 id="title">Welcome!</h1>
  <p id="message">Click a button to change the page.</p>

  <button id="changeButton">Change Message</button>
  <button id="colorButton">Change Color</button>
</body>
</html>

JavaScript Example 
const title = document.getElementById("title");
const message = document.getElementById("message");
const changeButton = document.getElementById("changeButton");
const colorButton = document.getElementById("colorButton");

changeButton.addEventListener("click", function() {
  message.textContent = "You clicked the button!";
});

colorButton.addEventListener("click", function() {
  title.style.color = "purple";
  document.body.style.backgroundColor = "lightyellow";
});

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Create HTML elements with unique IDs.
  2. Add buttons for user actions.
  3. Select elements using document.getElementById.
  4. Use addEventListener to detect clicks.
  5. Change text using textContent.
  6. Change colors using style.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Add a button that changes the paragraph text.
  • Add a button that changes the page background color.
  • Change the heading color to your favorite color on click.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Create three buttons that change the page into three different moods.
  • Change both text and color with one button click.
  • Add a reset button that returns the page to its original style.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Button does nothing The ID in JavaScript may not match the HTML ID. Check spelling in getElementById.
Text does not change textContent may be misspelled. Use element.textContent = 'new text'.
Style does not change CSS property may be written incorrectly in JavaScript. Use camelCase, such as backgroundColor.
