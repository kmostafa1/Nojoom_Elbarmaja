JavaScript Example 
let secretNumber = 7;

const form = document.getElementById("guessForm");
const input = document.getElementById("guessInput");
const result = document.getElementById("result");

form.addEventListener("submit", function(event) {
  event.preventDefault();

  let guess = Number(input.value);

  if (guess === secretNumber) {
    result.textContent = "Correct! You guessed the number!";
    result.style.color = "green";
  } else if (guess > secretNumber) {
    result.textContent = "Too high! Try again.";
    result.style.color = "orange";
  } else {
    result.textContent = "Too low! Try again.";
    result.style.color = "blue";
  }
});

Guided Activity

Task: Build a digital counter with increase, decrease, and reset buttons. Then build a number guessing game.

Challenge: Add color feedback to the counter and attempts to the guessing game.

Accessible Forms

Use <form> to group user input, <label> to describe the input, and <input> to collect the user's answer.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Create the app layout with input, buttons, and result area.
  2. Create JavaScript variables for app data.
  3. Read user input using input.value.
  4. Convert input to a number when needed.
  5. Use if, else if, and else to make decisions.
  6. Test different cases and fix logic errors.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Change the secret number.
  • Add a message when the guess is empty.
  • Add a maximum number of attempts.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Add a counter color rule for positive, negative, and zero.
  • Add limited attempts to the number guessing game.
  • Add a message when the input is empty.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Guess is always wrong Input value may be text, not a number. Use Number(input.value).
Condition never runs Comparison operator may be wrong. Use === for exact comparison.
Counter display does not update The variable changed but the page text did not. Update countText.textContent after changing count.
