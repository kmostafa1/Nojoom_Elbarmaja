Safety Note for Children

This lesson may use characters, games, books, and images. Keep content safe and respectful.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Creative Character Cards</title>

  <!-- External CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- External JS file -->
  <script src="script.js" defer></script>
</head>
<body>
  <header>
    <h1>Creative Character Cards</h1>
    <p>Meet my favorite characters from games and stories.</p>
  </header>

  <button onclick="document.body.style.backgroundColor='lightyellow'">
    Change Background
  </button>

  <main class="card-container">
    <section class="card">
      <div class="card-icon">🐉</div>
      <h2>Fire Dragon</h2>
      <p>A powerful dragon that guards the mountain castle.</p>
      <p><strong>Power:</strong> Fire Breath</p>
      <button onclick="alert('You selected the Fire Dragon!')">
        Choose Dragon
      </button>
    </section>
  </main>
</body>
</html>
CSS Example 
.card {
  width: 250px;
  padding: 24px;
  border-radius: 20px;
  background-color: white;
  border: 2px solid #ddd;
  text-align: center;
  box-shadow: 0 8px 20px rgba(0, 0, 0, 0.12);
  transition: transform 0.3s ease;
}

.card:hover {
  transform: translateY(-8px);
}

.card button {
  padding: 10px 16px;
  border: none;
  border-radius: 12px;
  background-color: #312e81;
  color: white;
  cursor: pointer;
}

Guided Activity

Task: Create a Creative Character Cards page with at least four cards. Add one button that shows an alert and one button that changes the page background color.

Challenge: Add the JavaScript sneak peek without changing the main CSS project structure.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Build the complete creative card page structure.
  2. Add at least four themed cards.
  3. Apply the full CSS card design with hover effects.
  4. Add one onclick alert button.
  5. Add one onclick background color change button.
  6. Test both JavaScript preview interactions.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Change the alert message for each character.
  • Add another button that changes the background to lightblue.
  • Create one card button that says Selected! using onclick.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Add one alert message for each character card.
  • Add one button that changes the background to a theme color.
  • Add a selected state by changing button text with onclick.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Alert does not show onclick syntax may have missing quotes. Use alert('Message') with quotes around the message.
Background does not change JavaScript property may be misspelled. Use document.body.style.backgroundColor.
Card button style changed unexpectedly Button CSS may affect all buttons. Use a specific selector such as .card button.
