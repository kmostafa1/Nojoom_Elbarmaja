Safety Note for Children

This lesson may include personal text, images, or links. Keep your webpage safe.

  • Do not put your home address, phone number, school address, or private personal details on a webpage.
  • Use an avatar, drawing, icon, or safe sample image instead of a real personal photo unless an adult approves.
  • Use copyright-safe images or images provided by the teacher.
  • Ask an adult before publishing any webpage online.
  • Be kind and respectful. Do not write content that could hurt, embarrass, or expose another person.
  • Do not copy code from unknown websites without teacher guidance.

HTML Example 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Webpage</title>

  <!-- External CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- External JS file -->
  <script src="script.js" defer></script>
</head>
<body>
  <h1>Hello, World!</h1>
  <h2>About This Page</h2>
  <h3>My First Section</h3>

  <p>This is my first webpage built with pure HTML.</p>
</body>
</html>

Guided Activity

Task: Create a page called My First Webpage with your name, h1, h2, h3, and one paragraph.

Challenge: Add h2 and h3 headings to create a clear content hierarchy.

Build Steps

Follow these steps to complete the lesson in a clear order.

  1. Create a new HTML file.
  2. Add the basic document structure: html, head, title, and body.
  3. Add one h1 heading and one paragraph.
  4. Add a small style block inside the head.
  5. Change the page background color and heading color.
  6. Save the file and open it in the browser.

Try This Change

Make one small change, refresh the page, and observe what happens.

  • Change the background color to your favorite soft color.
  • Change the h1 text color.
  • Add one more paragraph about something you enjoy.

Level Up Tasks

Finished early? Try one of these extra challenges.

  • Add a second paragraph and style it with a different text color.
  • Add a small welcome message using h2.
  • Create a second version of the page with a different background color.

Debugging Corner

Use this checklist when something does not work as expected.

Problem Possible Reason Fix
Page is blank The HTML file may not be saved or opened correctly. Save the file and refresh the browser.
Heading does not appear The h1 tag may be misspelled or placed outside body. Check that content is inside the body tag.
Color does not change CSS may be missing braces or semicolons. Check { }, property names, and semicolons.
